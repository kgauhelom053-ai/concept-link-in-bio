# Amahle Khumalo — concept link-in-bio page

Link-in-bio page concept for a **fictional** Cape Town food & travel creator: profile, social links, featured video, link list, recent posts, newsletter sign-up and brand-collab CTA.

**Concept design — not a real client.** The creator, stats and links are placeholders.

- Plain HTML/CSS/JS, no build step
- Animated gradient background, staggered blur-in reveals, hover micro-interactions
- Two-column on desktop, single column on mobile

Designed & built by Kgauhelo Mokoena (Cape Town). Photos: [Unsplash](https://unsplash.com) (Unsplash License).
